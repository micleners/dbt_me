Buying time is not avoidance — it keeps you from a regrettable action so you can revisit the problem later with more control. Pick just one category that feels possible right now:

- **A — Activities:** small absorbing actions (tidy a drawer, a walk, bake).
- **C — Contributing:** help someone; shift focus outward.
- **C — Comparisons:** to a tougher past time, or how far you've come (without invalidating the pain).
- **E — Emotions (opposite):** funny videos, upbeat music — generate a different feeling.
- **P — Pushing away:** mentally box the problem and set a time to revisit it.
- **T — Thoughts:** fill the mind — count backward by 7s, name states/animals, a puzzle.
- **S — Sensations:** safe intense input — ice cube, cold water, a strong scent.

See the source page for examples in each category.
