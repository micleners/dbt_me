# DBT Emotion Regulation: Being Effective (E2)

## Overview

This DBT skill focuses on actively accomplishing necessary tasks to meet needs and progress toward goals. According to the material, "the skill of being effective refers to actively doing what needs to be done so that you will have your needs met or in order to move closer to a certain goal." The exercise emphasizes that completing tasks generates positive emotions and breaks cycles of avoidance and depression.

## Key Sections

### Introduction
The resource explains how accomplishing goals improves emotional well-being. It acknowledges that depression can make even basic tasks seem overwhelming, recommending small, incremental progress to build momentum.

### Instructions: Two-Part Framework

**Part One: Short-Term Goals**
- Focus on daily tasks including basic self-care (showering, eating)
- Address work/study obligations
- Include postponed responsibilities
- Break each goal into specific, actionable steps

Example short-term goals provided:
- Getting a shower
- Eating a healthy breakfast
- Completing work activities
- Cleaning the apartment

**Part Two: Long-Term Goals**
- Identify meaningful pursuits aligned with personal values
- Reference the "Actions Based on Values" worksheet for broader life areas
- Select one priority goal and outline implementation steps

Example long-term goal: pursuing semi-professional painting with exhibition aspirations
